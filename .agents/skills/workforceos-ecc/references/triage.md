# Chief-of-staff triage adaptation

Derived from ECC agents/chief-of-staff.md at the pinned commit. This workflow serves
the existing authorized owner; it does not create a replacement Winston.

Use only authorized connected channels. Classify the content:
- ACTION: a question, deadline, failure, payment issue, or request needing action.
- MEETING: scheduling information needing reconciliation with the actual calendar.
- INFORMATION: facts requiring summary or record.
- LOW PRIORITY: routine items without an obligation; retain unless archiving is authorized.

Check substantive obligations before sender/category heuristics. Automated senders
may carry important failures, interview updates, payment receipts, or deadlines.
Draft in the user's voice. Send only under existing explicit send authority;
otherwise save the draft. Record actual action receipts, owners, due dates, and
follow-up. Calendar/task writes need their own existing authorization.

Do not auto-archive, send, alter calendars, or push relationship records merely
because the upstream example suggests it. Never manufacture another worker's reply.
Briefings cover relevant schedule, required action, completed actions with receipts,
overdue follow-ups, and exact blockers. Label unavailable channels unavailable.
